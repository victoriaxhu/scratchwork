# Erdős problem #1082: Distinct distances, no three collinear

**Statement.** Let A be a set of n points in the plane with no three on a line. Does A determine at least ⌊n/2⌋ distinct distances?

**Known results.** A companion question, whether some single point sees at least ⌊n/2⌋ distances, was answered negatively: Harborth gave an 8-point set where each point sees only 3 distances, and a 42-point example was posted on the erdosproblems.com forum.
