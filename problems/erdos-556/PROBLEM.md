# Erdős problem #556: 3-colour Ramsey numbers of cycles

**Statement.** Bondy–Erdős: for every n ≥ 4, the 3-colour Ramsey number of the n-cycle satisfies R(Cₙ; 3) ≤ 4n − 3.

**Known results.** Łuczak proved R(Cₙ; 3) ≤ (4 + o(1))n. Kohayakawa–Simonovits–Skokan settled large odd n and Benevides–Skokan large even n; the inequality for every n ≥ 4 is open.
